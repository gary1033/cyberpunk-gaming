# 三章流程與三個結局完成紀錄

更新：2026-09-08。範圍：章節轉場、三結局可達性、第二與第三章的選擇及後果。

## 章節與存檔

- 行動點耗盡不再自動跳章；地圖提供休整，恢復 20 點且保留調查進度。
- 第一章完成推理及章末收束後，才能前往第二章比特風暴網咖；第二章完成倉庫調查、核對正和科技備忘錄及收束後，才能前往第三章回聲網路總部。
- 章節、地點與行動點在場景成功切換後一起更新。無效目的地、重複點擊或轉場失敗不會先扣點或留下錯誤章節。
- 對話與轉場中暫停存檔，避免保存沒有對話游標的半段劇情；結束後即可保存。舊存檔補入新決策的預設值，繼續遊戲時恢復可操作狀態。
- 修正對話分支意外繼續播放另一選項、選項給予的證據未入庫、隱藏選項可被觸發，以及離開場景後延遲回呼仍操作已移除節點的問題。

## 結局條件

三個結局共同要求：進入第三章、完成蕭博士對質、安全救出浩然、封存核心證據，並持有記憶覆寫技術報告、正和科技資金流向與高層授權令。

| 結局 | 額外條件 | 屋頂的最終選擇 |
|---|---|---|
| A 正義之光 | 趙明信任、完成保護證人身份的舉報包與公開證據鏈；黑市妥協不超過一次 | 公開真相 |
| B 灰色交易 | 完成共同調查與救援要求 | 主動接受交易 |
| C 記憶重生 | 核對三段凱的記憶、回應迴響、接受融合並明確同意恢復記憶的代價 | 恢復記憶 |

屋頂會顯示每個結局缺少的條件；未選擇時不會自動套用 B。收集比例僅供顯示，不再代替核心調查。結局播放結束才標記案件完成，並解鎖辦公室尾聲；存讀檔及尾聲回放保留同一結局。

## 已接入的選擇

| 選擇 | 實際後果 |
|---|---|
| 接受／拒絕第一章蛇女交易 | 第二章開場使用不同入口資訊；拒絕者仍可透過小鬼或下水道推進 |
| 購買黑市記憶 | 增加一次妥協，取得記憶樣本與倉庫地圖 |
| 入侵交易系統 | 記錄身份曝光及額外義眼使用，取得交易帳本並可調查樣本 |
| 拒絕記憶交易 | 不領取交易獎勵，改由倉庫取得必要線索 |
| 保護幽靈 | 保存其證人身份，提高信任，取得通訊頻率與倉庫位置 |
| 出賣幽靈 | 降低信任、增加妥協，額外取得帳本；公開結局回收身份曝光後果 |
| 交由趙明／自行保存核對結果 | 記錄第二章證據通道；公開路線須再完成第三章舉報包 |
| 封存／釋放／融合迴響 | 記錄迴響去向及記憶態度；只有明確同意融合才能選 C，釋放的隱私代價會在公開結局回收 |

凱的記憶分三段揭露：曾參與調查、曾簽署自願條款、後來撤回同意仍遭覆寫。第三段必須先完成對質並封存證據；找到浩然和真正救出浩然也分成兩個步驟。

本輪新增 13 段對話，使用既有 37 件證據與圖片。舉報包、三段記憶核對及迴響處置以劇情旗標和既有證據組合表示；設計總檔中尚未建立的新證據與圖像仍是提案。
