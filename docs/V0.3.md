# V0.3：可回訪調查與阿傑查證流程

更新日期：2026-09-19。來源為現有 V0.2 工作樹；原有未提交修改保留。本輪依改善提案首批範圍製作。程式版本為 `0.3`，尚未重新匯出 Windows 試玩包；原有 V0.2 ZIP 不包含這次更新。

## 玩家會遇到的改變

- **問話順序不再漏掉必要委託資料。** 九種開場語氣／問題組合都會交付委託信、工作證、酒吧收據。回辦公室可整理委託袋，補救已漏線索的舊存檔。
- **可以離開酒吧再問。** 「拿收據回問阿傑／核對照片」保留入口；照片能接回後室調查，重問不重複增加證據與好感，也不清掉施壓紀錄。
- **分支各自收尾。** 修正阿傑出示收據、蛇女找晶片／接受交易、相簿安慰四段接到未選回答的問題；相簿仍走共同證據收尾。問工作室地址也直接接案，不再插入未問的信任回答。
- **阿傑推理多了一次真正查來源的行動。** 掃描只提供七分鐘時間差；玩家先記待查假設，核對收據編號與終端重送紀錄，再決定如何詢問阿傑。可暫停、改想法、存讀檔或先查別處。
- **猜測和對外行動分開。** 私下推論不充分時可修正，不扣好感、不封主線；明知無法指認卻逼問，仍留下不可靠證詞及歷史責任。回訪台詞會立即回應自願核對或施壓。
- **證據板可捲動並明確選取。** 滾輪、觸控滑動與按鈕支援後期證據量；選第一張讀內容，選第二張看關係，再按同一張取消。結果顯示推論及來源界線；不能支持的組合不扣分。
- **配對只計一次。** 同向、反向、存讀後重連都不累加；舊存檔的重複配對與虛高數值會重新整理。進度分母只計目前持有證據可形成的配對，不把未接入的證據當成漏查。

## 操作一遍新流程

1. 在辦公室接案；若讀入舊檔缺收據，按「調查 → 整理美玲留下的委託資料」。
2. 到深淵酒吧，可先看看周圍，再從「調查 → 拿收據回問阿傑／核對照片」繼續。
3. 「讀取收據／整理待查假設」消耗首次掃描的 20 能量；後續重看沿用已保存的掃描。
4. 選擇先查終端、證詞時間或監控，再開「核對終端重送紀錄」。七分鐘交易重送與後室三分鐘監控清場分開核對，不能互相代替。
5. 支持或修正假設後，使用「帶核對結果詢問阿傑」。自願核對、不使用證詞或施壓的後果沿用既有案件紀錄。
6. 開證據板查看「待驗證／已支持／已修正」摘要；先選一張證據閱讀，再選另一張核對。

## 後續對話修訂：開場與阿傑

依「參考小說用語與對話，不要太 AI 式對話」繼續修訂。共改 **11 組對話、60 個文字欄位（59 段台詞／旁白、1 個選項）**，涵蓋接案、委託袋、酒吧初訪／回訪、假設與核對、證詞／撤回、後室及監控。角色、段落數、跳轉、條件、證據、好感與存檔效果均未改動。

寫作參考為[老舍《駱駝祥子》第四章](https://zh.wikisource.org/zh-hant/駱駝祥子/4)中祥子回車廠的對話。這裡取用的寫法是：人物惦記的車、錢、吃飯會影響他先問什麼；動作和沒回答的部分也能表達關係。遊戲台詞由本作人物與情境重新寫成。

- **美玲先惦記弟弟能不能回話。** 收尾改為「要是找到他，先讓他打個電話給我。說一句也好。」保留三天失聯、十一點來電、工作室與播放器線索。
- **凱以觀察和短問句推進。** 刪掉替恐懼下定義、替沉默講道理的句子；開場以催不到尾款和桌上物件帶出處境。猜錯時承認「我把兩件事扯在一起了」。
- **阿傑在意自己會被拿去說成什麼。** 被逼問後說「我連他的臉都沒見著」，回訪會翻舊帳；自願核對仍只確認收銀紀錄。
- **操作提示放在選項與證據板。** 阿傑不再說「離開本章前回來」；施壓選項仍明示不可靠指認、施壓紀錄及本章可更正。七分鐘重送與三分鐘監控仍分開。

本批驗證：文字遮罩比對確認所有非文字內容一致；相關資料檢查 **79 通過、0 失敗、0 警告**；實際調查流程 **1,004 次斷言通過**；全量分頁 **10,673 項通過、強制斷句 0**。分頁涵蓋桌面 1280×720、手機模式 1280×720／854×480，共 98 組稽核資料、1,755 段及 732 個選項檢查。既有回訪測試只更新被改寫台詞的比對文字，情境與檢查保留；斷言總數也包含隨分頁變動的推進檢查。

## 後續迭代：蛇女交易可以暫緩，人物記得先前的態度

本批先處理三個可改善之處：聽完報價就被迫成交或拒絕、蛇女不回應先前態度、交易台詞用金句代替具體條件。共修訂 4 組對話、25 個既有文字欄位，新增 2 段條件式反應及 1 個暫緩選項。

- **聽報價不等於承諾。** 晶片交易新增「晶片先收起來，之後再談」。暫緩不改好感、證據、交易次數或路線，也不關閉入口；可以存檔、離開酒吧、回來再選。

- **交易條件具體可判斷。** 她明說原件留下、取一份副本，副本可能被轉手；成交選項明示交易紀錄。面具商人說清樣本、倉庫地址、優先報價權與記帳。拒絕仍保留原有診所／倉庫調查路徑。
- **兩人有不同說話目的。** 蛇女把找晶片說成「你本來也得去」，試探玩家願不願意交東西；商人禮貌談貨、身份和帳。市場舊債與酒吧晶片交易仍分開，沒有簽樣本交易的人不會被說成欠了舊債。

## 後續迭代：蕭博士的證據追問

本批修改初次對質、覆核站掃描與紀錄追問，共 3 組對話。蕭博士先談病人的風險、把責任推向覆核與行政程序；玩家再用具體紀錄逼近他的決定，最後才聽到他怕正和收回原型而繼續寫入的供述。

- 出示回執、接收碼及本地簽章後，增加兩種追問：**維持器能獨立運行，為何留下寫入**，或**簽下待覆核之前，是否看過撤回**。各有一段回答，最後接回共同供述。
- 追問中可以先離開核對資料。`xiao_accountability=admitted` 與完成旗標改在實際供述出現時設定，選中問題本身不算取得供述；再次進入可重問，無新存檔欄位。
- 拿付款單直接推斷操作人仍會被反問，流程不鎖死。證據未齊仍可記為有爭議，不把推測補成供述。
- 初次對質保留救援前／後的不同台詞；已救出浩然時不再說他仍在維持椅上。問話不替玩家完成救援，也不取代公開案件所需的三份核心原件。
- 凱以短問句追查，蕭博士用病況、行政與技術工作替自己辯解；減少「你要追究的是這個決定」一類替玩家總結劇情的台詞。
