# NEON MEMORIES 角色 Image2.0 提示詞

本文件整理目前 `CharacterData` 與 `CharacterDesign` 內 12 位角色的 Image2.0 生成提示詞。每位角色各有兩種版本：

- **A. 概念設定表 prompt**：16:9、白底、三視圖、表情、裝備拆解、色票，適合做角色設定稿。
- **B. Q 版遊戲立繪 prompt**：延續目前遊戲 SVG 的 chibi / cel-shaded 方向，適合做 Godot 對話立繪或角色頭像。

統一世界觀：2087 年九龍延伸區，賽博龐克黑色偵探冒險遊戲，主題包含記憶交易、企業陰謀、地下黑市、霓虹雨夜與義體掃描。

## 通用輸出建議

- 概念設定表：`16:9, clean white background, organized grid layout, high resolution, character reference sheet, cyberpunk noir, anime concept art, cel-shaded`
- Q 版立繪：`256x384 vertical portrait, chibi game sprite, clear silhouette, dark neon background, Godot dialogue portrait, cel-shaded anime style`
- 通用避免：不要寫實照片、不要中世紀奇幻、不要歐美超級英雄風、不要厚重 3D 寫實盔甲、不要偏離賽博龐克黑色偵探世界觀。
