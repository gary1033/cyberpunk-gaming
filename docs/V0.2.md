日期：2026-09-09。狀態：已產出 V0.2 Windows 試玩包；V0.1 保留。真人試玩尚待執行。

## 目標

第三章可先救人或先保存證據，保留安全隔離、來源核驗、蕭博士對質與三結局條件。沿用現有地點、角色、39 項證據與美術，不新增圖片。

## 事件約定

| 事件 | 前提 | 玩家操作 | 結果與替代方法 |
|---|---|---|---|
| 進入實驗室 | 完成入口與走廊核對 | 自行選擇搜尋、設備核對或對質 | 初次進場只提示可做的事，不自動完成對質 |
| 設備隔離報告 | 已定位走廊 | 比對設備序號及報告版本，再判讀隔離順序 | 取得既有技術報告；錯誤可重試，也能改問蕭博士 |
| 幽靈協助 | 實際使用幽靈入口且尚未分派 | 選撤離或取證；確認前可取消 | 一次分派，另一任務仍可自行核對；已完成任務不能追溯分派 |
| 資金原件保管核對 | 已有授權令 | 幽靈協助／企業具名調閱／自行比對紙本 | 核驗後才封存；展示摘要不等同原件，可取消或改道 |
| 撤離準備 | 走廊已定位 | 接應／企業具名開門／自行核對離線出口 | 準備完成才可救援；保留隔離程序與本人意願 |
| 停用企業資格 | 使用企業入口 | 明確確認停用 | 後續只能離線查證，入口及已發生具名調閱紀錄保留 |
| 蕭博士對質 | 走廊授權令 | 主動追問，允許暫停；依救援狀態回應 | 報告可由此取得，結案仍須完成對質 |

首次完成救援／原件封存時記錄實際先後，不以玩家閱讀順序猜測。舊檔已完成的目標與結案結果不撤銷，也不補寫未發生的操作歷史。已保存的報告不重複發放；舊檔若尚未救援，仍須完成新出口核對，已救出的浩然不必重救。

## 驗證結果

- 原有七條新遊戲通關與 18 組自由調查路徑均通過。18 組的入口條件由前兩章實際遊玩取得，沒有直接灌入入口或結局旗標；涵蓋三入口 × 兩種主要順序 × 三主結局，不是所有支線組合窮舉。
- 取消、重訪、兩次設備誤判、錯誤保管鏈／出口、停用資格改道、過期按鈕、協助只能分派一次、舊檔與途中存讀檔、最後決定後禁止改寫紀錄均通過。負向測試使用存檔樣本調整先決條件。
- 完整檢查第一次 943 通過／1 失敗／0 警告。唯一失敗為兩段新文字句中切頁；調整斷句後，全量分頁重跑 10,258 項通過、0 句中切頁（93 組正式對話加 1 組最長行動紀錄測例，三尺寸共 1,689 段／711 選項檢查）。沒有把該次完整紀錄改寫成全數通過，也未再次重跑整套。
- 最終 GPU 桌面與兩種手機尺寸版面 1,464 項通過，含新增調查目標區與捲動後的取消按鈕。GPU 實際新遊戲通關完成先救人路線；加速流程不代表真人遊玩時間。
- 正式匯出 exit 0；以同版 Godot 引擎載入正式 PCK，再執行 18 組新遊戲通關，全部通過、0 引擎錯誤。檢查封包版本為 0.2、開發測試不在封包內，並確認 18 種入口／先後／結局組合互不重複。這是封包資源驗證，並非宣稱 release exe 執行測試腳本。
- Windows release exe 從解壓檔啟動成功，透過屬於該測試程序的視窗關閉訊息正常退出，exit 0；仍有既有 ObjectDB／2 resources still in use 清理訊息，原因待追蹤。第一次以 Process.CloseMainWindow 關閉隱藏視窗未成功，之後改對該程序的遊戲視窗送出 WM_CLOSE；不是遊戲中途當機。
