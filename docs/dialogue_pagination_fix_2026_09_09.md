# 對話斷句與分頁修正

日期：2026-09-09。

## 修正結果

完全移除桌面 50、手機 30、選項 32 字的固定分頁限制。現在依實際字型大小、文字框寬度與可用文字區高度量測；能放下就不分頁，需要分頁時優先使用完整句尾或原有段落界線。逗號、頓號與空格不再作為一般切頁依據。

打字效果先排好整段文字再逐字顯示，避免字出現時重新換行。續頁標記改為「續讀 x/y」，與「下一段」區分；觸控產生的模擬滑鼠事件不會重複推進。保留原有換段、選項、旗標與證據效果，只在首頁套用劇情效果。

逐筆檢查四段過長複句後，整理了幽靈身份、救援交接、浩然照護、獨立原件核對的斷句。人物意思、交易代價、選項及分支條件不變。
