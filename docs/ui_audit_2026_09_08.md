## 仍需下一輪處理

1. **證據板可讀性。** 實際通關可完成連線，但字體過小，標題／說明貼近裝飾框；十多項線索時已難掃讀。建議下一輪先做卡片內距、字級與選中放大檢視，再驗收 39 項證據下的捲動、連線及觸控。
2. **小橫向畫面的 CG 遮擋。** 現在優先確保文字和選項可讀，因此 854×480 的下半畫面被對話框占用，交付證據的手部動作會被擋住。需要加「暫時隱藏對話框看 CG」或另做小畫面分區；本輪未把這項列為已完成。
3. **美術方向需主觀驗收。** 新 CG 已減少皮膚光滑感，但是否達到理想風格仍由玩家觀看決定；這輪沒有重畫六張趙明表情或全面重畫背景人物。
4. **既有音效缺口。** 四段正式短音效仍未交付，沿用安全略過缺檔；本輪沒有加入新的音效或改動配樂。
